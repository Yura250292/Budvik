# Expo SDK 54

Проєкт свідомо на SDK 54, а не на найновішому: Expo Go для новіших версій
немає в App Store (Expo перестала його туди публікувати з SDK 55), а власник
дивиться застосунок на iPhone. Решта мобільних проєктів у цій екосистемі теж
на 54 — один Expo Go на всі.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.
