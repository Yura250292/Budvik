# Будвік27 — застосунок покупця

Expo / React Native. Каталог, пошук, сканер кодів, кошик і оформлення
замовлення для покупців магазину інструментів.

## Запуск

```bash
cd mobile
npm install
npx expo start
```

### Куди застосунок ходить по дані

Адреса API береться зі змінної `EXPO_PUBLIC_API_URL`; без неї — бойовий
`https://www.budvik27.com`.

**Телефон не бачить localhost машини розробника.** Щоб працювати проти
локального сайту, підніміть його і вкажіть адресу в локальній мережі:

```bash
# у корені репозиторію
npm run dev

# тут, у mobile/ — IP машини, не localhost
EXPO_PUBLIC_API_URL=http://192.168.1.106:3000 npx expo start
```

Емулятор Android бачить машину як `http://10.0.2.2:3000`.

### Що не працює в Expo Go

Сканер (`expo-camera`), біометрія (`expo-local-authentication`) і пуші
потребують збірки з нативним кодом:

```bash
npx eas build --profile development --platform ios
```

Каталог, пошук, кошик і оформлення в Expo Go працюють.

## Структура

```
src/api/       клієнт /api/v1 і типи відповідей
src/lib/       токен (SecureStore + біометрія), кошик
src/theme.ts   кольори з manifest.json сайту
src/app/       екрани (Expo Router)
  (tabs)/      Головна, Каталог, Пошук, Кошик, Кабінет
  product/     картка товару
  brand/       товари бренда
  scan.tsx     сканер
  checkout.tsx оформлення
```

## Правила, які легко порушити

**Ціни застосунок не рахує.** Сервер віддає `price` уже з урахуванням акції та
ролі, а `basePrice` — лише коли є що закреслити. Будь-яка арифметика зі
знижками на клієнті рано чи пізно розійдеться з сайтом.

**Кратність пакування.** У товару буває `packQty` — його продають лише по 10,
по 5 тощо. Кнопка «+» додає пачку, а не штуку; сервер усе одно округлить
угору, і без цього кількість стрибала б сама.

**Типи в `src/api/types.ts` — контракт.** Установлену збірку не можна оновити
примусово, а рев'ю в магазині триває днями. Несумісна зміна форми відповіді
ламає застосунки, які вже в руках у людей: такі зміни їдуть під `/api/v2`.

**`/api/v1/` внесено в bypass фаєрвола Vercel.** Роут поза цим префіксом на
проді віддасть застосунку сторінку челенджу з кодом 429, а не дані —
локально при цьому все працюватиме.

## Збірка APK для тестування

Локального тулчейна на машині немає (ні JDK, ні Android SDK), тож збираємо в
хмарі Expo:

```bash
npx eas login          # безкоштовний акаунт Expo, один раз
npx eas init           # створює projectId, дописує його в app.json
npx eas build -p android --profile preview
```

Профіль `preview` дає саме **APK** (`buildType: "apk"`), а не AAB: AAB
встановлюється лише через Play Market, а тестову збірку роздаємо файлом.

Готовий файл кладеться в `assets/app/Budvik27.apk` у корені репозиторію —
звідти його віддає `/api/app/shop/download` тим, хто увійшов як ADMIN,
MANAGER або SALES. Сторінка встановлення: `/admin/mobile-app`.

⚠️ `EXPO_PUBLIC_API_URL` у профілях вказує на прод. Збірка має сенс лише
після того, як `/api/v1/*` задеплоєно — інакше застосунок отримає 404 на
кожен запит.
