# Будвік27 — застосунок покупця

Expo / React Native. Каталог, пошук, сканер кодів, кошик і оформлення
замовлення для покупців магазину інструментів.

## Запуск

```bash
cd mobile
npm install
npx expo start
```

### Куди застосунок ходить по дані

У розробці адреса береться від самого Metro: він знає, з якої адреси телефон
щойно завантажив бандл. Нічого вказувати не треба — досить підняти сайт:

```bash
# у корені репозиторію
npm run dev

# тут, у mobile/
npx expo start
```

**Не задавайте `EXPO_PUBLIC_API_URL` заради локальної роботи.** Змінна
головніша за адресу від Metro, тож зашитий у неї IP переживе зміну мережі й
застосунок мовчки стукатиме в стару адресу. Вона потрібна лише для того, щоб
навести dev-збірку на прод. Без неї в релізі лишається
`https://www.budvik27.com`.

Емулятор Android бачить машину як `http://10.0.2.2:3000`.

### Що не працює в Expo Go

Сканер (`expo-camera`), біометрія (`expo-local-authentication`) і пуші
потребують збірки з нативним кодом:

```bash
npx eas build --profile development --platform ios
```

Каталог, пошук, кошик і оформлення в Expo Go працюють.

## Структура

```
src/api/       клієнт /api/v1 і типи відповідей
src/lib/       токен (SecureStore + біометрія), кошик
src/theme.ts   кольори з manifest.json сайту
src/app/       екрани (Expo Router)
  (tabs)/      Головна, Каталог, Пошук, Кошик, Кабінет
  product/     картка товару
  brand/       товари бренда
  scan.tsx     сканер
  checkout.tsx оформлення
```

## Правила, які легко порушити

**Ціни застосунок не рахує.** Сервер віддає `price` уже з урахуванням акції та
ролі, а `basePrice` — лише коли є що закреслити. Будь-яка арифметика зі
знижками на клієнті рано чи пізно розійдеться з сайтом.

**Кратність пакування.** У товару буває `packQty` — його продають лише по 10,
по 5 тощо. Кнопка «+» додає пачку, а не штуку; сервер усе одно округлить
угору, і без цього кількість стрибала б сама.

**Типи в `src/api/types.ts` — контракт.** Установлену збірку не можна оновити
примусово, а рев'ю в магазині триває днями. Несумісна зміна форми відповіді
ламає застосунки, які вже в руках у людей: такі зміни їдуть під `/api/v2`.

**`/api/v1/` внесено в bypass фаєрвола Vercel.** Роут поза цим префіксом на
проді віддасть застосунку сторінку челенджу з кодом 429, а не дані —
локально при цьому все працюватиме.

## Збірка APK для тестування

Локального тулчейна на машині немає (ні JDK, ні Android SDK), тож збираємо в
хмарі Expo:

```bash
npx eas login          # безкоштовний акаунт Expo, один раз
npx eas init           # створює projectId, дописує його в app.json
npx eas build -p android --profile preview
```

Профіль `preview` дає саме **APK** (`buildType: "apk"`), а не AAB: AAB
встановлюється лише через Play Market, а тестову збірку роздаємо файлом.

Готовий файл кладеться в `assets/app/Budvik27.apk` у корені репозиторію —
звідти його віддає `/api/app/shop/download` тим, хто увійшов як ADMIN,
MANAGER або SALES. Сторінка встановлення: `/admin/mobile-app`.

⚠️ `EXPO_PUBLIC_API_URL` у профілях вказує на прод. Збірка має сенс лише
після того, як `/api/v1/*` задеплоєно — інакше застосунок отримає 404 на
кожен запит.

## Знімки екранів (Playwright)

Metro віддає застосунок і як веб через `react-native-web`, тож ті самі
компоненти можна відкрити в браузері й **побачити** зміни, а не здогадуватись:

```bash
npx playwright install chromium   # один раз
npx expo start                    # в іншому терміналі
npm run screens -- shots          # знімки в mobile/shots/
```

Це не заміна перевірці на пристрої: react-native-web малює не все так само,
як натив — шрифти, тіні й таб-бар відрізняються, камера й біометрія не
працюють узагалі. Але верстка, порожні стани, заглушки завантаження й те, чи
не зникає нижня навігація при переході, видно тут точно так само — а цикл
правки секунди замість збірки.

Скрипт вимикає CORS **у самому браузері**, а не на сервері: нативний `fetch`
не шле `Origin`, тож застосунку CORS не потрібен, і на проді його свідомо
немає — на тому, що крос-доменний запит упирається в preflight, тримається
безпека `/api/device/session`.

Помилки консолі скрипт друкує в кінці. Саме так знайшлися падіння
`SecureStore` у вебі й багатосекундний спінер на обраному.

## Адреса API в розробці

Застосунок бере її від самого Metro (`Constants.expoConfig.hostUri`), тож
після зміни мережі нічого правити не треба. Змінна `EXPO_PUBLIC_API_URL`
лишається головнішою — і саме тому її **не варто задавати заради локальної
роботи**: зашитий IP переживе зміну мережі й переб'є адресу від Metro.

У веб-стенді (`npm run screens`) `hostUri` порожній, тож хост беремо з адреси
самої вкладки — вона теж прийшла від Metro. Раніше там була потрібна змінна, і
без неї стенд мовчки знімав **прод**: сторінка малювалась, дані приходили,
просто не ті — старі знімки розділів і один банер замість трьох.

Місце змінної — навести dev-збірку на прод навмисно:

```bash
EXPO_PUBLIC_API_URL=https://www.budvik27.com npx expo start
```

⚠️ Якщо на екрані назавжди лишились заглушки завантаження — перше, що варто
перевірити, це чи не змінилась адреса Mac у мережі (`ipconfig getifaddr en0`).
Саме так виглядає застосунок, який стукає в стару адресу: помилки немає,
запит просто нікуди не доходить.
